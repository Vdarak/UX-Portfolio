# Project Case Study: Canvas Chat

## Overview
- **Product Title**: Canvas Chat
- **Role**: Personal Project (Tinkering/Vibe Coding)
- **Tags**: Gemini API, Canvas UI, Interaction Design, Brainstorming

## The Problem
Traditional AI chat interfaces are linear and restrictive. Users scroll endlessly through a single thread, losing the context of where ideas branched or how different concepts connect. For complex problem-solving and brainstorming, linear logs are a major cognitive bottleneck.

## The Solution
I built a canvas-style AI chat interface where users can spawn multiple conversations in the same infinite space. This design supports both micro-level deep dives and a macro-level understanding of connected ideas.

### Key Features
1. **Infinite Canvas UI**: Free-form movement, zooming, and panning inspired by Figma's spatial interface.
2. **Branching Message Nodes**: Users can click any message in a chat history to spawn a brand new branch, visually representing divergent thought paths.
3. **Multi-Agent Orchestration**: Spawn multiple distinct agents simultaneously on the same canvas, letting them cross-examine each other or tackle separate sub-tasks.
4. **Gemini API Integration**: Leverages highly responsive LLM endpoints to dynamically stream message blocks to individual node frames.
